# Ahmed Ragab Portfolio

هذا المشروع هو موقع شخصي احترافي يعرض بيانات صاحب المشروع، خدماته، خبرته، مهاراته، وأعماله السابقة في نموذج Portfolio/Personal Website.

## الوصف

الموقع مصمم كصفحة واحدة (Single Page) باستخدام HTML وCSS وJavaScript، ويحتوي على:

- قسم ترحيب Hero Section
- قسم About Me
- قسم الخدمات
- قسم Resume
- قسم Portfolio
- قسم Testimonial
- قسم Contact
- شريط التنقل الجانبي
- تأثيرات تفاعلية للتمرير والـ Typed Animation

## التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript
- jQuery
- Typed.js
- Font Awesome

## هيكل المشروع

```text
protifilo/
├── Html files/
│   └── index.html
├── css files/
│   └── style.css
├── javascript files/
│   └── main.js
├── photos file/
│   └── الصور المستخدمة في المشروع
├── README.md
```

## التشغيل محلياً

للمشاهدة المحلية للموقع، يمكنك إما:

1. فتح ملف `Html files/index.html` مباشرة في المتصفح
2. أو تشغيل خادم محلي داخل المجلد الرئيسي باستخدام أحد الطرق التالية:

### باستخدام Python

```bash
cd "c:\Users\ahmed\OneDrive\Desktop\projects\protifilo"
python -m http.server 8000
```

ثم افتح المتصفح على الرابط:

```text
http://localhost:8000/Html%20files/
```

## ملاحظات مهمة

- بعض الروابط داخل الصفحة تتطلب ملفات أو مسارات توجد في المشروع مثل ملف السيرة الذاتية والملفات الصور.
- تأكد من صحة مسارات الصور والملفات قبل النشر أو الاستخدام.
- إذا كنت تريد تخصيص الاسم أو المعلومات الشخصية، يمكنك تعديلها داخل ملف HTML وملف JavaScript.

## التخصيص

لتعديل بيانات الشخص:

- الاسم: داخل `Html files/index.html`
- الوصف المهني: داخل نفس الملف
- الروابط الاجتماعية: داخل `nav` و`social-icons`
- مهاراتك وخبرتك: ضمن أقسام Resume وSkills
- الصور: داخل مجلد `photos file/`
